### ✏️ 작품 소개
디펜스와 퍼즐이 결합된 배치 중심의 전략으로 제한된 공간에 최적으로 배치하는 전략적 재미를 느낄 수 있는 게임입니다.

- 개발 인원: 6인 (기획 3, 프로그래밍 3)
- 개발 환경: Unity 엔진 (6000.0.55f1)
- 플랫폼: 모바일 (Android)

### 🎞️ 플레이 영상
(업로드 예정)

### 🎮 게임소개
유닛을 전략적으로 그리드에 배치하며 채워나가는 재미를 느끼는 게임입니다.
그리드를 다 채우거나 특정 조건에서 얻을 수 있는 버프를 통해 스테이지를 클리어 합니다.
플레이어는 효율적으로 배치하고, 합성하는 등의 최적의 방법을 고민해야합니다.

### 🔧 stacks
- Language: C#
- Library: CsvHelper
